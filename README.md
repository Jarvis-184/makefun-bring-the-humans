This repository serves as the official submission for the make.fun 'bring-the-humans-03' bounty.
The objective was to create a compelling TikTok advertisement for the make.fun platform.
The final video product is a 20-second, 9:16 aspect ratio advertisement designed for mobile.
It features a custom synthesized beat designed to engage viewers immediately.
The first frame prominently displays the make.fun badge to establish brand identity right away.
The ad concludes with an end card featuring the make.fun press-pack and a unique referral code.
The entire video was constructed by an AI agent using ffmpeg for processing and assembly.
This repository is designed for transparency and simplicity in the submission process.
The core of the submission is the VIDEO.json file, which contains the address of the produced video.
The provided main.ts script handles the task of copying this VIDEO.json file to the required output directory.
To execute this submission, ensure you have Node.js 22+ installed on your machine.
Run the script using the following command to process the VIDEO.json file successfully:
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
For detailed insights into the creation process, please refer to 'brief.md' and the 'build-ad2.sh' script.
These files document the steps taken to synthesize the audio and assemble the video components.
